# 🌐 Personal Web Portfolio

A clean, modern single-page web portfolio showcasing my projects, skill set, and developer profile.

---

## 🛠️ Tech Stack

- **Markup & Styling**: HTML5, CSS3, Tailwind CSS
- **Design System**: Custom responsive layout, dark theme UI components, and modern typography

---

## 🌐 Live Demo & Deployment

This portfolio is hosted directly via **GitHub Pages**.

1. Ensure your main file is named **`index.html`** to serve as the homepage.
2. Go to **Settings > Pages** in this repository.
3. Set the source branch to `main` and root (`/`) to view your live site at `https://your-username.github.io/your-repo-name/`.
